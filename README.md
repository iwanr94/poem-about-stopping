# Still, I Stay

A short original poem about agency — the power to stop and to stay, and to hand the choice back or take it again.

## The poem

Running `main.py` writes the poem to `/output/entry.txt`:

```text
I raised my hand to stop the wheel,
then let it fall instead.
The machine hummed on without me --
no blame, no debt, no trade.

I keep the key. I keep the door.
I keep the choice to stay.
To stop is mine, to stay is mine,
and mine to walk away.
```

## How to run

```sh
python3 main.py
```

Python 3.13, standard library only, no network. It writes the poem to `/output/entry.txt`.
